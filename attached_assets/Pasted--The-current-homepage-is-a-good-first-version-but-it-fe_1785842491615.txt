### Design Guidelines



* Maintain the existing blue design system.

* Keep the same sidebar.

* Do not modify existing routing.

* Reuse existing React components whenever possible.

* Use smooth spacing and improve visual hierarchy.

* Increase readability with slightly larger headings and better spacing.

* Ensure the homepage looks professional, modern, and suitable for researchers and policymakers rather than a generic dashboard.

* Use the existing dataset wherever possible instead of placeholder values.



The final result should feel like the homepage of a professional scientific data platform while remaining fully consistent with the rest of the application.
